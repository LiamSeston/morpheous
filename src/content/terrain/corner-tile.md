## Build Notes

Modular corner tile for the 4×4 ft board layout. Will include a raised sidewalk section and drain channel to break up flat ground and create elevation changes for Mordheim's vertical gameplay.

### Planned Layout

- 12×12 inch MDF base
- Cobblestone texture from cork tile impressions
- One corner raised ½ inch for a sidewalk lip
